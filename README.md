# panoslevedogiannis.github.io

Προσωπική σελίδα, στη ρίζα του GitHub Pages:
**https://panoslevedogiannis.github.io**

Ένα αρχείο, χωρίς build και χωρίς εξαρτήσεις: `index.html`. Το μόνο που
έρχεται απ' έξω είναι οι γραμματοσειρές.

## Δύο γλώσσες

Τα αγγλικά είναι το κείμενο της σελίδας· τα ελληνικά ζουν σε `data-el` πάνω σε
κάθε στοιχείο και ο διακόπτης `ΕΛ` τα εναλλάσσει, κρατώντας την επιλογή στο
`localStorage`. Στοιχείο χωρίς `data-el` μένει αγγλικό — χρήσιμο για ονόματα
και επωνυμίες, που δεν μεταφράζονται.

## Σύνδεση με τη διπλωματική

Το κουμπί δείχνει στο `/eeg-bci-hand/`, που είναι το
[άλλο αποθετήριο](https://github.com/PanosLevedogiannis/eeg-bci-hand) στον ίδιο
τομέα. Ίδια γραμματοσειρά και παλέτα, ώστε οι δύο σελίδες να διαβάζονται ως ένα
σώμα δουλειάς.

## Ενημέρωση

Άλλαξε το `index.html` και κάνε push στο `main`. Το Pages χτίζει σε ένα-δύο
λεπτά και σερβίρει την HTML με δεκάλεπτη cache, οπότε για έλεγχο χρησιμοποίησε
σκληρή ανανέωση.
